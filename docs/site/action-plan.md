- **ארכיטקטורה:** `stages.ts`, `clients.ts`, `fullPackage` הם מקור אמת יחיד.
  התמחור נגזר ולא משוכפל. חישוב ההנחה מאומת: 1,000+1,300+1,600+1,900 =
  5,800, פחות 4,500 = 1,300. ✅
- **`VideoTestimonial`:** דפוס facade, כתוביות VTT, תמלול לצד הווידאו.
  ה-MP4 לא נטען עד לחיצה.
- **טופס:** ולידציה חוסמת, טלפון ישראלי נדחה לפני בקשה, honeypot,
  `form_submit_failed` עם סיבה, העברת פוקוס בהצלחה.
- **ביצועים:** LCP 1,952ms במובייל חלש, CLS 0, 0 אנימציות אינסופיות.
- **נגישות:** 0 כשלי WCAG AA בניגודיות, axe נקי.
- **SEO:** prerender, canonical, JSON-LD, sitemap.
